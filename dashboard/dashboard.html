ApplyTrail 求职投递追踪

开始使用

  1. 自动记录：在 Greenhouse / Lever / Workday / Ashby / LinkedIn Easy Apply / Indeed 等网站提交申请后，出现 “Thank you for applying” 页面时会自动记录，右下角弹出提示（可撤销）。
  2. 一键记录：在任何职位页面点击浏览器右上角的插件图标（或按 Alt+Shift+J），自动抓取公司、职位、地点、JD，确认后保存。抓不到 JD 时，先在网页上选中 JD 文字再点图标。
  3. 邮件识别：用 Gmail 网页版时，会自动识别 OA 邀请、面试邀请、拒信和 Offer，更新对应投递的状态（可撤销）。
  4. 面试准备：在这里点开任意一条记录，可以记录每轮面试、查看 JD 关键词、签证要求、一键打开面经 / 薪资调研链接。

点右上角 ☁ 登录同步 用 Google 账号登录，换电脑时登录同一个账号，记录就都在。
